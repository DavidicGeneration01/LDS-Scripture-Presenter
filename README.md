# Scripture Presenter

A local presentation tool for scripture readings for audience; although, there several scripture presenter out there but there is no presenter on the Book of Mormon, Pearl of Great alongside with other scripture presenter software such as likes of EasyWorship, BibleShow, Pro Presenter etc. LDS Scripture Presenter is here to close the gap and serve the general public. The operator view searches scripture references, keeps a short history, and can open a live window for projection.

# Addition Information
- Bible references are fetched from public KJV data.
- Latter-day Saint scripture references are fetched from JSON scripture data when the app is online.
- `BroadcastChannel` and `localStorage` keep the operator and live windows in sync.
- The manual tab is available for custom text or offline use.
